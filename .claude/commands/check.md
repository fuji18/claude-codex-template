# 品質チェックの一括実行

品質チェックの実行と機械的なエラー修正を `test-runner` subagent(Haiku)に委譲するコマンド。長いログを司令塔のコンテキストに流さない。**チェック項目・自動修正の範囲・禁止事項・サマリー形式は `test-runner` の定義(`.claude/agents/test-runner.md`)が正**で、ここには重複記述しない。

**引数:** なし(任意で対象を絞ってよい。例: `/check lintだけ`)

## 手順

1. **委譲**: Agent ツールで `test-runner` subagent を起動する。引数で対象が絞られていればプロンプトに含める。完了を待つ間、司令塔に他の独立したタスクがあれば並行して進めてよい
2. **未解決の問題への対応**: test-runner が「司令塔の判断が必要」として返した問題(テスト期待値と実装のどちらが正しいかの判断、設計判断を伴う型エラー等)は、司令塔が該当箇所を読んで修正し、失敗したチェックのみ test-runner に再実行させる。どうしても解消しない問題は無理に修正せず「未解決」としてユーザーに報告する
3. **報告**: test-runner のサマリー(チェック結果テーブル・自動修正した内容・未解決の問題)をそのままユーザーに提示する
