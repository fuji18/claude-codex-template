# 要求: autopilot の全体管理 Issue・ローカルの手間削減・econ モード対応

前回(`.steering/20261007-autopilot/`)の続き。

1. **全体管理 Issue**: GitHub 上の 1 枚の Issue で全チケットの状態を見渡し、そこから一時停止・再開できる
   - 状態の正は各チケットのラベル・PR のまま(2 系統にすると割れる)。全体管理 Issue は**表示と操作**
   - 人手が要る停止は全体管理 Issue にコメントで残る(通知の受け口)
2. **ローカルの手間削減**: ターミナルに張り付かない
   - `--background` で起動し、ログ・停止をコマンドで扱う
   - 停止理由の通知(コメント + 任意の通知コマンド)
   - 中断した自分の作業(同じブランチ上の未コミット変更)では止まらずに再開する
3. **econ(モード B)対応**: 枠を温存したまま自動で積む
   - Claude は計画と PR 作成だけ。実装は `delegate-codex.sh impl` をループ(シェル)が直接叩く
   - PR は draft、検収なし(CI に委ねる)。`package.json` のライフサイクル差分があれば人間に返す
   - draft はマージされず枠を埋め続けるので、econ 用の WIP 上限を別に持つ
   - Codex が使えないとき(exit 3)に Sonnet fork へ自動で落とさない(枠を使うため)
