# 要求: Codex をレビューに使うためのハーネス整備と autopilot の指摘対応

## 背景

Codex はこれまで実装(`delegate-codex.sh impl`)にしか使っていなかった。レビューにも使う可能性が出てきたため、
既存の `review` 経路と周辺を点検した。唯一のレビュー実行(`20260826-092548-55359`)は、未コミットの変更が
3 件あったのに対象が空(`main...HEAD`)のまま「指摘なし」で完了していた。あわせて autopilot(2026-10-07)の
レビュー指摘を直す。

## 要求

1. review は分岐点から作業ツリーまで(未コミット・未追跡を含む)を対象にし、差分が無ければ枠を使わずに止まる
2. 空・形式外の出力を成功扱いにしない。指摘件数はホストが数える。長い出力は黙って切らない
3. AGENTS.md を読み取り専用の委託と矛盾しない形にし、レビュー規約(Review guidelines)を置く
4. 観点・重大度ラベルを Claude 側の `code-reviewer` と揃える。無人実行でも review を許可する
5. autopilot: fork PR・権限の無いレビュアーで止まらない / `/fix-pr` がリモートに追いつく /
   許可拒否を停止理由に出す / クラウドで黙って死ぬループを起動しない / 判定の一時失敗で止まらない /
   econ の tasklist が検収項目で詰まらない
6. `.codex/hooks.json` の絶対パスと manifest の漏れを直す

## スコープ外

- GitHub 上の Codex ボットがコメント(COMMENTED)として投稿するレビューの自動検出(投稿形式が未確認のため。
  誤検出すると `/fix-pr` が空回りしてループが止まる)
<!-- main-edit-ok --> (テンプレート自体の改修。ハーネス層のため司令塔が書く)
