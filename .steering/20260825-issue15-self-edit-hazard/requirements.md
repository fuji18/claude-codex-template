- Issue: #15(P2 / depends なし)
- 根拠: `docs/template-dev/codex-delegation-plan.md` §9

## 背景

bash はスクリプトを**逐次読み込み**する。実行中にファイルが書き換わると次に読むオフセットがずれ、無関係な行で構文エラーになって死ぬ。

2026-08-23、段階4 の委託(タスクに `delegate-codex.sh` の改修を含んでいた)が実際にこれで落ちた。**Codex 側は全タスクを完遂していたのに run record は `running` のまま孤児化した** — status と summary を書くのは死んだ親プロセスの仕事だったため。

テンプレート自身の開発では委託対象にハーネス層が入るのが常態なので、対処しなければ再発する。当座の防波堤として `delegate-codex.sh` は委託禁止領域(`CLAUDE.md` / `AGENTS.md` §4)に置いてあるが、これは運用規約であって機構ではない。
