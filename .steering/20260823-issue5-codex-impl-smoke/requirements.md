# 要求定義: 段階3 の実機委託(Issue #5 受け入れ条件 #1・#2)

このステアリングは **`delegate-codex.sh impl` を実機の Codex で 1 本完走させるための対象**である。
Issue #5 の受け入れ条件「impl モードが実機の Codex で 1 チケットを完走する」「終了コード 0 を実機で確認する」を満たす。

題材は捨て作業ではなく、段階3 で実際に欠けている成果物を選んでいる:
**新設した入口検査(5-1〜5-5)に対応する運用手順が `docs/template-dev/codex-delegation-plan.md` §12 に無い。**
委託が入口で止まったとき、司令塔は「どの検査で止まり、何をすれば復旧するか」を毎回スクリプトの
ソースから読み解くことになる。§12 はそのためのランブックなので、ここに 1 節足すのが正しい置き場所。

## 満たすこと

- §12.6 の直後に §12.7 として「委託が入口検査で止まったとき」を追加する
- 新設した検査それぞれについて、**終了コード / 何が起きているか / 復旧手順 / この検査が空振りする条件**を表で示す
- 既存の文体・見出しレベル・表の書式に合わせる

## 満たさないこと

- 既存節の書き換え(§12.6 以前には触れない)
- スクリプトの変更
