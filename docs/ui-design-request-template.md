# AIデザイン依頼テンプレート

<!--

  「いい感じにして」等の曖昧指示は出力がブレるため、下記を具体的に埋めて渡す。
  設計の「なぜ」は docs/ui-design-guidelines.md を参照(このファイルはその §11 の単体版)。

## 使い方

1. 下の **「記入用テンプレート」** をコピーし、各項目を自分のプロダクトで埋める
2. 埋めた全文を AI に渡す
3. AI がまず **デザインプラン**(color 4-6 / type 2役 / layout)を出す → 承認 → 実装、の順で進める

**3つのコツ**(これだけで出力の質が変わる):
- ターゲットと目的は**具体的に**(抽象語ほどブレる)
- **「避けたい印象」を必ず書く**(望む印象より効くことがある)
- **加点を最低1つ**指定する(タイポの落差 / 意外な1色 / 見せ場)。指定しないと"無難"に着地する

---

## 記入用テンプレート(コピーして使う)

```text
Webサイト/画面のデザインを提案してください。

## 対象サービス
サービス名 / 概要:

## ターゲット(具体的に)
年齢層・利用シーン・抱えている悩み(例:ITに不慣れな個人事業主):

## 目的(この画面のたった1つの仕事)
例:無料登録させる / 世界観を伝える / 問い合わせを増やす:

## treatment(演出の度合い)
実用系(管理・設定) / エディトリアル系(LP・共有したくなる):

## 希望する印象(2〜3語の組み合わせ)
例:上品 × 親しみやすい × 静か:

## 避けたい印象(必須)
例:子どもっぽい / 派手すぎ / 情報過多。加えて次の "AI定番" を避ける:
紫→青グラデ、グラスモーフィズム+グローオーブ、Inter一択、全部中央寄せ、
何でも角丸lg、絵文字の見出しマーカー

## ビジュアルスタイル(1つ選ぶ)
Bold Minimalism / Editorial Craft / Warm Organic / Interactive Kinetic
(Bento UI 等のトレンドも可。ただし "定番の逃げ" に注意):

## 情報設計・掲載順序
見せる順を指定。例:Hero → 課題提起 → 解決策 → 特徴 → 実績/口コミ → FAQ → CTA:

## レイアウト
PC:2〜3カラム / スマホ:1カラム。非対称・広め余白を許容:

## デザイントークン(役割で定義)
- Color: bg / surface / text / muted / accent(1色) / semantic(good/warn/danger)
  ※ニュートラルはアクセント寄りに色味を仕込む(純粋グレー禁止)
- Type: display(表情ある見出し) / body / mono・caption。タイプスケール固定
- Spacing: 4px グリッド / Radius / Shadow(印象で選ぶ:柔=角丸大、硬=シャープ)

## タイポ(日本語)
本文16px以上 / 行間1.7〜1.8 / 見出しはやや太め:

## コンポーネントとUI状態
button / input / card を default / hover / focus / disabled / loading / empty / error まで:

## アクセシビリティ
コントラスト4.5:1以上 / 色だけで情報を伝えない / フォーカス可視:

## 加点(最低1つ入れる)
タイポの落差 / 意外な1色 / シグネチャーモーメント のどれかを効かせる。
リスクは1箇所だけ取り、他は静かに。

## 出力形式
まず「デザインプラン」(color 4-6 / type 2役 / layout を1〜2文)を提示 → 承認後に実装。
```

## 記入例(埋めるとこうなる)

参考として、架空プロダクトで埋めた例。**具体性・避けたいリスト・加点**の書き方に注目。

```text
Webサイト/画面のデザインを提案してください。

## 対象サービス
サービス名:ヨムログ / 概要:読んだ本を1行で記録し、月末に読書傾向をふり返るアプリ

## ターゲット(具体的に)
30〜40代・通勤中や就寝前にスマホで使う・「読んだ本を忘れてしまう/積読が可視化されない」悩み

## 目的(この画面のたった1つの仕事)
ランディングで「無料で記録を始める」を押させる

## treatment(演出の度合い)
エディトリアル系(共有したくなる、読み物的な落ち着き)

## 希望する印象(2〜3語の組み合わせ)
知的 × 静か × 手触りのある

## 避けたい印象(必須)
子どもっぽい / SaaSっぽい派手さ / 情報過多。
AI定番を避ける:紫→青グラデ、グラスモーフィズム+グローオーブ、Inter一択、
全部中央寄せ、何でも角丸lg、絵文字の見出しマーカー

## ビジュアルスタイル
Editorial Craft(雑誌風・非対称・明朝/セリフ・1px罫)

## 情報設計・掲載順序
Hero(1行キャッチ+記録デモ) → 積読の課題 → 1行記録の解決 → 月末ふり返りの特徴
→ 利用者の声 → FAQ → CTA

## レイアウト
PC:2カラム(左に大見出し、右に本の書影) / スマホ:1カラム。余白広め、左寄せ非対称

## デザイントークン
- Color: bg=生成りの紙 / surface=少し明るい紙 / text=墨 / muted=暖グレー /
  accent=インクブルー1色 / semantic=別枠
- Type: display=明朝(詰めトラッキング) / body=システムゴシック / caption=モノスペース
- Spacing: 4pxグリッド / Radius=小さめ(シャープ寄り) / Shadow=使わず1px罫で階層

## タイポ(日本語)
本文16px / 行間1.75 / 見出しやや太め

## コンポーネントとUI状態
記録入力欄・保存ボタン・本カードを、default/hover/focus/disabled/loading/empty/error まで

## アクセシビリティ
コントラスト4.5:1以上 / エラーは色+アイコン+文言 / フォーカス可視

## 加点(最低1つ)
「タイポの落差」を効かせる:見出しは大きな明朝、本文は小さめ。見せ場はHeroの記録デモ1つに集中

## 出力形式
まずデザインプラン(color 4-6 / type 2役 / layout)を提示 → 承認後に実装
```
